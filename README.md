# gerenciador-tarefas
Projeto desenvolvido durante o curso de Desenvolvimento Front-End do programa Bolsa Futuro Digital do Instituto Hardware BR.

## Objetivo
Desenvolver uma aplicação web interativa que permita ao usuário cadastrar, visualizar, concluir, filtrar e
excluir tarefas, utilizando JavaScript para manipular os elementos da página e o localStorage para
armazenar os dados. 

## Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
- LocalStorage
